## Purpose

让审查者点击父级按钮（⏷）时，快速跳转选中当前组件的最近父级可审查元素，支持逐级向上浏览组件树。

## ADDED Requirements

### Requirement: 点击父级按钮选中最近父级

当存在已选中元素且该元素有可审查的父级祖先时，点击父级按钮 SHALL 选中该最近父级可审查元素。

#### Scenario: 选中子元素后点击父级按钮

- **WHEN** 用户已选中一个元素，且该元素存在带 `data-source-file` 属性的祖先
- **THEN** 点击父级按钮后，选中态切换到最近的父级可审查元素，hover overlay 隐藏，选中框和操作按钮重绘到新元素上

#### Scenario: 无父级可审查元素时点击

- **WHEN** 用户已选中一个元素，但该元素不存在带 `data-source-file` 属性的祖先
- **THEN** 点击父级按钮无任何效果

#### Scenario: 无选中元素时点击

- **WHEN** 当前没有选中任何元素
- **THEN** 点击父级按钮无任何效果
